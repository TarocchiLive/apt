Arcana World APT repository

Signed packages for Debian and Ubuntu, amd64 and arm64. Requires glibc 2.34 or newer (for example Debian 12+ or Ubuntu 22.04+).

sudo apt-get update
sudo apt-get install -y ca-certificates curl
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://tarocchilive.github.io/apt/tarocchilive-archive-keyring.gpg | sudo tee /etc/apt/keyrings/tarocchilive.gpg >/dev/null
sudo chmod 0644 /etc/apt/keyrings/tarocchilive.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/tarocchilive.gpg] https://tarocchilive.github.io/apt stable main" | sudo tee /etc/apt/sources.list.d/tarocchilive.list
sudo apt-get update
sudo apt-get install arcana-world

Repository maintenance

Download both Linux release archives and checksums.txt from the same upstream release. Run python3 publish.py VERSION DOWNLOAD_DIRECTORY --revision REVISION --gnupghome PRIVATE_KEY_DIRECTORY --signing-key FINGERPRINT with Python 3.12+, dpkg-deb, xz and GnuPG. The script verifies archive checksums, rebuilds packages and signs stable metadata. Increment the Debian revision when repackaging an already published upstream version; preserve existing package files. Recheck ELF dependencies when packaging a new upstream version. Review, commit and push the generated files to main to publish via GitHub Pages. Keep the private signing key outside this repository; renew and publish the public key before expiry.
